# Tech Stack & Conventions
- **Framework:** Next.js 16 (App Router).
- **Styling:** Tailwind CSS v4 (CSS-first configuration via `@theme` in `globals.css`).
- **Language:** TypeScript.
- **Animations:** Framer Motion (use `motion`).
- **Icons:** Lucide React.
- **State/Storage:** Client-side only. Use `localStorage` to persist notes. No backend.
- **Components:** UI components go in `/components`. Add `"use client"` to interactive components.
